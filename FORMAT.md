# Формат персонажа — `gm-character/v1`

Единый контракт, в который нейронка приводит вставленный текст чарника.
Один и тот же JSON рендерит и GM-экран, и импортёр. Не изобретаем формат каждый раз —
парсер на сервере всегда выдаёт **ровно эту форму** (см. `web/character.schema.json`).

## Зачем

Игрок кидает мастеру текст персонажа в любом виде (D&D Beyond экспорт, скрин→OCR,
рукописный список, «плут 3, ЛОВ 16, скрытность +7…»). Его приводят к объекту ниже, и GM-экран
добавляет карточку на вкладку **Партия** (броски, HP-степпер, состояния) — аддитивно, не
затирая уже загруженных.

Два пути привести к формату (оба дают **ровно эту форму**):
- **Локально, под подпиской (основной)** — скилл `parsing-character-sheets` из
  `.claude/skills/`: без API-ключа и без сервера, отдаёт JSON для вставки в поле импорта.
- **Локальный сервер (опционально)** — `POST /api/parse-character` прогоняет текст через
  Claude по строгой схеме. Платный (твой ключ), поэтому только для локального запуска, не на прод.

## Объект `gm-character/v1`

```jsonc
{
  "schema": "gm-character/v1",     // всегда эта строка
  "name": "Тень",                  // имя персонажа (обяз.)
  "player": "Кирилл",              // имя игрока или null
  "class": "Плут",                 // класс без уровня
  "subclass": "Скаут",             // архетип/подкласс или null
  "level": 3,                      // общий уровень (число)
  "race": "Полурослик",            // раса или null
  "background": "Преступник",      // предыстория или null
  "alignment": "ХН",              // мировоззрение или null

  "ac": 15,                        // класс доспеха (число)
  "hp": { "max": 24, "current": 24, "temp": 0 },   // current/temp могут = max/0
  "speed": "30 фт",                // строка (может включать полёт/лазание)
  "initiative": 3,                 // модификатор инициативы (число, обычно = мод ЛОВ)
  "prof": 2,                       // бонус мастерства (число; ур.1–4 = 2)

  "abilities": { "str": 10, "dex": 16, "con": 14, "int": 12, "wis": 10, "cha": 8 },
  // все шесть, значения характеристик (не модификаторы). Ключи строго str/dex/con/int/wis/cha.

  "saves": ["dex", "int"],         // владения спасбросками (те же ключи; [] если нет)

  "skills": "Скрытность +7, Акробатика +5, Восприятие +3",  // строка «Навык +N, …» или "—"

  "passives": { "perception": 14, "investigation": 11, "insight": 10 },
  // пассивные значения (10 + мод + владение). Отсутствующие можно опустить.

  "senses": "тёмное зрение 60 фт",   // строка или "—"
  "languages": "Общий, Полуросличий, Воровской жаргон",  // строка или "—"

  "attacks": [
    {
      "name": "Рапира",
      "hit": 5,                    // бонус к попаданию (число); null если атака без броска
      "damage": "1d8+3",           // кости урона; "" если нет
      "type": "колющий",           // тип урона/примечание к атаке
      "note": "скрытная атака +2d6 при преимуществе",  // опц.
      "extra": "2d6"               // опц. доп. кости урона (складываются к damage при броске)
    }
  ],

  "spellcasting": {                // null, если персонаж не колдует
    "ability": "Интеллект",
    "dc": 13,                      // Сл спасброска заклинаний
    "attack": 5,                   // бонус атаки заклинанием
    "slots": { "1": 4, "2": 2 },   // ячейки по кругам (ключ = круг строкой)
    "spells": [
      { "name": "Волшебная стрела", "level": 1, "desc": "3×1d4+1 силового, автопопадание" }
    ]
  },

  "features": [                    // черты/умения одной строкой каждая
    "Скрытная атака 2d6",
    "Хитрое действие (Отход/Рывок/Засада бонусом)",
    "Ловкий побег"
  ],
  "gear": ["короткий лук (+4, 1d6+3)", "воровские инструменты", "50 зм"],

  "conditions": [],                // текущие состояния (заполняет мастер за столом, парсер обычно [])
  "notes": ""                      // свободные заметки
}
```

## Правила для парсера (в системном промпте сервера)

- Возвращать **только** JSON объекта `gm-character/v1`, без markdown-заборов и комментариев.
- `hit` — число (бонус к попаданию), либо `null` для атак-эффектов без броска. `damage` — строка кубов `NdM(+K)` либо `""`.
- Характеристики — **значения** (8–20+), не модификаторы. Инициатива/спасы/навыки — **модификаторы**.
- Если чего-то нет в исходнике — не выдумывать: строки → `"—"`, массивы → `[]`, `spellcasting` → `null`, числа не-угадываемые → 0 c пометкой в `notes`.
- Русские подписи в значениях; ключи полей — строго латиницей как в схеме.
- `prof` по уровню, если не указан: ур.1–4=2, 5–8=3, 9–12=4, 13–16=5, 17–20=6.
- `current`/`temp` по умолчанию = `max`/`0`.

## Совместимость с рендером GM-экрана

Карточка на вкладке «Партия» использует те же кнопки, что бестиарий:
- **⚔ атака** = d20 + `attacks[].hit`; **🎲 урон** = `damage` (+`extra`);
- **спас** = d20 + (мод характеристики + `prof`, если ключ в `saves`);
- **+иниц** = d20 + `initiative` → в трекер инициативы с `hp.current`;
- HP-степпер меняет `hp.current`; чипы состояний — `conditions`.

Схема-валидатор: `web/character.schema.json` (JSON Schema, `additionalProperties:false`).
